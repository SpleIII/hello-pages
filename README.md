# hello-pages

React-приложение на Vite, которое собирается в CI и готовится к публикации
на **GitHub Pages**. Отличие от `hello-static`: здесь есть полноценный
сборщик, зависимости из npm и отдельный каталог `dist/` на выходе.

## Что делает пайплайн

| Job | Что происходит |
|---|---|
| `build` | `npm install` → `npm run build` → сборка уезжает в артефакт Pages |
| `deploy` | публикация `dist/` на GitHub Pages |

Сборка и публикация разнесены по двум job'ам: деплой стартует только после
успешной сборки, поэтому сломанный фронтенд на сайт не попадёт.

## Путь публикации

Сайт лежит не в корне домена, а по адресу `/hello-pages/`, поэтому в
`vite.config.js` задан базовый путь:

```js
export default defineConfig({
  plugins: [react()],
  base: '/hello-pages/',
})
```

Без этой строки ассеты искались бы в корне домена и сайт открывался бы
пустым.

## Структура

```
.
├── index.html         # точка входа для Vite
├── package.json       # зависимости и скрипты
├── vite.config.js     # конфигурация сборщика
└── src/
    ├── main.jsx       # монтирование React в #root
    ├── App.jsx        # разметка страницы
    └── index.css      # оформление
```

## Запуск

```bash
cd hello-pages

# разработка с горячей перезагрузкой
npm install
npm run dev

# продакшн-сборка
npm run build
npm run preview
```

## Что на странице
